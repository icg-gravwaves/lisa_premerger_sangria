Having established the methodology by which we will use the inpainting technique to search for premerger signals, we apply the method to the Sangria dataset. We use the same dataset as we used early for the zero-latency filter and search for signals that are between 14 days and 2 hours before merger. Following section~\ref{sec:zerolatency_sangria} we remove signals 2 hours before merger so that a loud merger doesn't interfere with rapid observation of subsequent signals.

The results are presented in Figure~\ref{fig:inpainting_estimate} where we show signal-to-noise ratio as a function of the time before merger. We also show in Table~\ref{tab:when_found} the details of how long before merger each signal was identified and with what signal-to-noise ratio. This is compared to the previous zero-latency results. We notice that not being restricted to search at discrete times before merger allows us to detect some of the signals days earlier. We remind that the zero-latency search could be run at more times before merger, but the computational cost would grow linearly with the number of times before merger searched.

We also observe that for signals 0 and 3 the zero-latency search identifies the signal 7 days before merger, whereas the inpainting search identifies it 14 days before merger. Additionally, signal 4 is found with a larger signal-to-noise ratio with the inpainting search 14 days before merger. Although there is some overlap between signal 3 and signal 4, which we will discuss shortly, this is a direct comparison and both searches should be affected the same way by this. We believe that this improved efficiency at 14 days before merger is due to how the data is conditioned. For the zero-latency search we apply a long taper to the waveform over the first $\sim$ day of data to avoid any abrupt start effects and to remove and wraparound from the ringdown. The same is not performed for the inpainting. This results in more power being available for the 14-day before merger search. This is not a fundamental limitation. We chose to demonstrate the zero-latency method, and inpainting, on 28 days of data, but if more data was available, with non-negligible power there, once could simply increase the analysis window. However, for the zero-latency search, this increases the chance of gaps being present, which it cannot handle.

\subsection{Gaps}
\label{subsec:inpainting_gaps}

One of the main motivations for the inpainting approach was that it could effectively handle gaps in the data. To demonstrate this, we reanalyse signal 0 with gaps added to the data 10.5 - 9.5, 5.5 - 4.5 and 2.5 - 1.5 days before merger. We then search for signal 0 using inpainting to mitigate the gaps and show the results in Figure~\ref{fig:signal_zero_timeline}. The plot shows the result of searching for the signal with the zero-latency search without gaps, the inpainting search without gaps and the inpainting search with the gaps added. We note that the overall signal-to-noise ratio recovered when gaps are present is smaller, which is expected because data, and signal power, is missing, but the search still accrues signal-to-noise at times when data is available, maximizing the chance of finding a signal like this. If, for example, signal 0 was 4 times further away, such that the signal-to-noise were reduced by a factor of 4 compared to what we see, the inpainting or zero-latency search could find this a little before 1 day before merger. However, if the data contains gaps then the zero-latency search would not be able to identify this 
signal at all with our current implementation, whereas the inpainting search ginds it just after 1 day before merger.
