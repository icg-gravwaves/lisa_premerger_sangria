\section{Power loss due to resolvable Galactic Binary foreground}
\label{sec:gb_noise_snr_loss}
\updated{As demonstrated in Figure~\ref{fig:psds}, the pre-merger analysis waveforms mainly terminate before the frequency where resolvable galactic binary noise contribution becomes significant.
To investigate this, we compare the expected signal-to-noise ratio loss when using different PSDs.
Firstly, we use the estimated Sangria-HM `day zero' PSD, which includes signals from all sources, this is `A Estimated' in Figure~\ref{fig:psds}.
We compare to the modelled PSD, `Model A/E', which contains unresolvable galactic binary foreground which would not be removed by any global fit analyses.}

\updated{The fraction of signal-to-noise ratio lost is shown in Figure~\ref{fig:gb_snr_loss}.
We see that for the signals at lower chirp masses, we can lose up to 17\% of power half a day before merger.
For heavier signals, and for times more than a few days before merger, the signal power loss is much less.
The few points where there seems to be a power `gain' (loss $<$ 0) are due to the inherent variability in estimating a PSD.
The signal-to-noise ratio loss is enough to show that global fit-style subtraction of resolved Galactic Binary sources will help optimise this technique, particularly as we move closer to merger, but is not significant enough that this subtraction is strictly necessary for pre-merger searches.
This finding is similar to what is shown in Section~\ref{sec:focused}, that the removal of signals from the data is desirable in some cases.
}

\section{Signal Removal}
\label{sec:signal_removal}
\updated{As discussed in Section~\ref{sec:focused}, the loudest signals from the data can match to templates in the bank even with the small amount of template power away from the merger.
The solution is to manually remove signals from the data as soon as they are known.
This is similar to the global fit challenge, but remains within the same source type.
To remove signals from the data, we assume that the signal is known perfectly, and the parameters of the injection are used to generate a waveform which is subtracted from the data.}

\updated{As shown in Figure~\ref{fig:removal_residual}, signal removal is not perfect, and some signal power remains.
The subtracted signal was produced using the same routines as in the dataset generation, and so there should not be a mismatch.
We encourage the release of the exact methods which were used to produce the datasets so that they can be independently recreated.}
