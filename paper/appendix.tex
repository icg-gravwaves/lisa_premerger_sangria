\section{Power loss due to Galactic Binary foreground}
\label{sec:gb_noise_snr_loss}
\updated{As demonstrated in Figure~\ref{fig:psds}, the pre-merger analysis waveforms mainly terminate before the frequency where resolvable galactic binary noise contribution becomes significant.
To investigate this, we compare the expected signal-to-noise ratio loss when using different PSDs.
Firstly, we use the estimated Sangria-HM `day zero' PSD, which includes signals from all sources.
We compare to the modelled PSD, which contains unresolvable galactic binary foreground which would not be removed by any global fit analyses.}

\updated{The fraction of signal-to-noise ratio lost is shown in Figure~\ref{fig:gb_snr_loss}, where we see that for the lightest systems, there can be some power loss.
This power loss is enough to show that global fit-style subtraction of resolved Galactic Binary sources will help optimise this technique as we move closer to merger, but is not necessary for pre-merger searches.
This finding is similar to what is shown in Section~\ref{sec:focused}, that the removal of signals from the data is desirable in some cases.}

\begin{figure}
   \centering
   \includegraphics[width=\columnwidth]{images/figure_11_GB_SNR_loss.pdf}
   \caption{
       \updated{Fractional signal-to-noise ratio loss for each signal caused by the resolvable Galactic Binary noise contribution.
       We see that signals at lower chirp masses are affected more, losing up to 15\% of power half a day before merger.
       For heavier signals, and for times more than a few days before merger, the signal power loss is much less.
       The few points where there seems to be a power `gain' (loss < 0) are due to the difference between an estimated PSD and the PSD model.}
   }
   \label{fig:gb_snr_loss}
\end{figure}

\section{Signal Removal}
\label{sec:signal_removal}
\updated{As discussed in Section~\ref{sec:focused}, the loudest signals from the data can match to templates in the bank even with the small amount of template power away from the merger.
The solution is to manually remove signals from the data as soon as they are known.
This is similar to the global fit challenge, but remains within the same source type.
To remove signals from the data, we assume that the signal is known perfectly, and the parameters of the injection are use to generate a waveform which is subtracted from the data.}

\updated{As shown in Figure~\ref{fig:removal_residual}, signal removal is not perfect, and some signal power remains.
We encourage the release of the exact methods which were used to produce the datasets so that they can be independently recreated.}

\begin{figure}
   \centering
   \includegraphics[width=\columnwidth]{images/figure_12_removal_residual.pdf}
   \caption{
       \updated{Residuals after removal for Signal 3.
       Equivalent plots for all signals are included in the data release.}
   }
   \label{fig:removal_residual}
\end{figure}

\updated{The remaining signal power still produces a small signal-to-noise ratio peak, as in Figure~\ref{fig:variable_removal}.
Early estimate parameter estimation routines may find parameters which remove more of the signal from the data, and so this may not be an issue in real LISA premerger analyses.}
